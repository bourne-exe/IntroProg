# IntroProg

C++ exercises from my introductory programming course at university. Each file covers one chapter of the course material, building from basic syntax to structured data. The code is written and executed in Qt Creator (also used in Swedish language).

## Contents

| File | Topic |
|---|---|
| `kap02FunkOchCppfiler.cpp` | Functions and C++ files |
| `kap03Variabler.cpp` | Variables |
| `kap04FunkInUt.cpp` | Function input and output |
| `kap05ifSatser.cpp` | If-statements |
| `kap06Flyttal.cpp` | Floating-point numbers |
| `kap07Heltal.cpp` | Integers |
| `kap08TestaKod.cpp` | Testing code |
| `kap09MerOmVariabler.cpp` | More about variables |
| `kap10MerOmFunktioner.cpp` | More about functions |
| `kap12Loopar.cpp` | Loops |
| `kap13charOchString.cpp` | Characters and strings |
| `kap14vektorer.cpp` | Vectors |
| `kap15Structar.cpp` | Structs |
| `main.cpp` | Entry point |

## Build and run

Requires a C++ compiler and CMake, or Qt Creator.

```
mkdir build && cd build
cmake ..
cmake --build .
```

## What I learned

- Writing and organising functions across multiple files
- Control flow with conditionals and loops
- Working with integers, floating-point numbers, characters and strings
- Using vectors and structs to model data
